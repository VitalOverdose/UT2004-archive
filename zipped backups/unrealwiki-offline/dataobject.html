DataObject

A DataObject is an Object that holds information for storage, for example GameProfile? is a data object to store a Single Player profile for UT2003.

Using Config Vars and .Ini Files isn't always the best solution fo storing information, sometimes you have to store a lot of information in various formats. Using DataObjects might be the solution for you.

In order to use DataObjects you need to have an instance of a GameInfo actor since that actor defines the DataObject functions.

DataObjects are saved into normal Unreal packages. You can store more than one object in a package if you want.

This functionality is not part of the stock UnrealEngine2?, it's only available in UT2003 and UT2004.

Functions

The following DataObject related functions have been defines in GameInfo

GetSavedGames

native final function Manifest  GetSavedGames();

This will return an instance of Manifest that contains a list of all saved DataObject packages. These are just the saved packages, it does not mean that a package listed in the manifest contains the DataObjects you use.

CreateDataObject 

native final function Object    CreateDataObject ( class objClass, string objName, string packageName );

This will create a new DataObject.

objClass
is the base class of the object: class'xGame.UT2003GameProfile'
objName
is the name of the object: "UT2003GameProfile". This is a unique identifier for the stored object, it has to be unique in that package or else it will overwrite existing objects with the same name.
packageName
is the filename/packagename of the DataObject

The result is the new Object (if succesfull). Note that the package has not been saved to the disk yet.

LoadDataObject 

native final function Object    LoadDataObject   ( class objClass, string objName, string packageName );

Load an existing DataObject, if the DataObject doesn't exist yet (either as saved file or previous created object) none will be returned;

DeleteDataObject 

native final function bool      DeleteDataObject ( class objClass, string objName, string packageName );

Delete an existing data object from the specified package. This does not remove the package file from the disk.

AllDataObjects 

native final iterator function  AllDataObjects   ( class objClass, out Object obj, string packageName );

List all DataObjects in the specified package.

SavePackage

native final function bool      SavePackage      ( string packageName );

This will save the package to disk, it will be saved to: Saves\<packagename>.uvx

DeletePackage

native final function bool      DeletePackage    ( string packageName );

This will delete the complete package from the disk.

Usage

Since DataObjects are normal Unreal Objects you can add anything you want. All variables (when changed from their default value) will be saved to the disk. You can also add functions to your DataObject, ofcourse these won't be saved to disk.

It's adviced to prefix (e.g. "SP_player1", "SP_player2") the package names so you can easily distinguish packages that contain your DataObjects and other DataObjects.

Example

An example object that hold some data

class MyDataObject extends Object;

var string PackageName;

var int savecount;

struct StructData
{
  var string Name;
  var string Value;
}
var array<StructData> MyData;

defaultproperties
{
  saveCount=0
  packageName="MDO_Test"
}

Example usage (warning: pseudo code)

class MyDataObject extends Whatever;

var array<string> objList;
var string objPreFix;
var MyDataObject ActiveObject;

function GetObjList()
{
  local manifest mf;
  local int i;
  objList.length = 0;
  mf = GameInfo.GetSavedGames();
  for (i = 0; i < mf.ManifestEntries.length; i++)
  {
    if (Left(mf.ManifestEntries[i], Len(objPreFix)) ~= objPreFix)
    {
      objList.length = objList.length+1;
      objList[i] = mf.ManifestEntries[i];
    }
  }
}

function IncreaseAllSaveCounters()
{
  local int i;
  for (i = 0; i < objList.length; i++)
  {
    ActiveObject = MyDataObject(GameInfo.LoadDataObject(class'MyDataObject', "MyDataObject", objList[i]));
    ActiveObject.saveCount++;
    GameInfo.SavePackage(objList[i]);
  }
}

function DeletePackagesWhereSaveCountIs(int higherThan)
{
  local int i;
  for (i = objList.length-1; i > 0; i--)
  {
    ActiveObject = MyDataObject(GameInfo.LoadDataObject(class'MyDataObject', "MyDataObject", objList[i]));
    if (ActiveObject.saveCount > higherThan)
    {
      GameInfo.DeletePackage(objList[i]);
      objList.remove(i, 1);
    }
  }
}

function CreateRandomSaveCountPackages(int num)
{
  local string tmp;
  while (num > 0)
  {
    tmp = objPreFix$"pkg"$rand(MaxInt);
    ActiveObject = MyDataObject(GameInfo.CreateDataObject(class'MyDataObject', "MyDataObject", tmp));
    ActiveObject.PackageName = tmp;
    ActiveObject.saveCount = rand(MaxInt);
    GameInfo.SavePackage(tmp);
    objList.length = objList.length+1;
    objList[objList.length-1] = tmp;
    num--;
  }
}

defaultproperties
{
  objPreFix="MDO_"
}

Example #2

Solid Snake: Here is an example on how to use all of the functions and what exactly is going on.

function TestDataObject()
{
local ceMissionProfile myObject; // ceMissionProfile subclassed from Object
local array<ceMissionProfile> DataObjects;

myObject = GameInfo.CreateDataObject(class'ceMissionProfile', "TestMission", "MissionPackage"); // This will make ceMissionProfile object called TestMission in a package called MissionPackage. 
// While the data has been created, it hasn't actually been saved yet (It currently exists as Save.tmn)

GameInfo.SavePackage("MissionPackage"); // This will save the the object [ceMissionProfile] into the MissionPackage.uvx now.

// This gets all of the objects from within the package
foreach GameInfo.AllDataObjects(class'ceMissionProfile', L, "MissionPackage") 
{
  DataObjects.Length = DataObjects.Length + 1;
  DataObjects[DataObjects.Length - 1] = L;
}

myObject = GameInfo.LoadDataObject(class'ceMissionProfile', "TestMission", "MissionPackage"); 
// This will load the object, ceMissionProfile with the matching name, TestMission in MissionPackage.

myObject.SetMissionTitle("Cleanse Area"); 
// Alter the object... we can now do it since the object is 'loaded'.

GameInfo.DeleteDataObject(class'ceMissionProfile', "TestMission", "MissionPackage"); 
// This deletes the object specified by Name and from within the Package name.

GameInfo.DeletePackage("MissionPackage"); 
// This deletes the package originally created by SavePackage().
}

// When packages are deleted and the objects added to it straight away, it doesn't actually delete.
// This is a way around the problem, and it works very well.
function DeleteMissionPackage(string Package)
{
  local object o;

  foreach PlayerOwner().Level.Game.AllDataObjects(class'Object', o, Package)
    PlayerOwner().Level.Game.DeleteDataObject(class'object', ""$o.Name, Package);
}
