UnrealWiki To Do

A wiki doesn't run itself. It's a bit like a garden: things grow, and you need to keep it tidy with a bit of trimming and weeding. Wikis rely heavily on  WikiGnomes to stay healthy.

This page lists things you can do to help. If you have a spare moment, there's always little things to do that add up to make a big difference to the usability of the place.

Things to do

Quick stuff

Got a couple of minutes?

  • clean up tutorials: if they only apply to UT, make them say so
  • browse through Category Category pages and identify those pages in every category that don't belong there; then either remove the wrong category links on those pages or "screen" them by adding an extra vertical bar at the end of the link, like [[Category Category|]].
  • wikify new pages: create inline links and add a "related topics" section
  • tag pages with Category Class (UT) or Category Class (UT2003)
  • clean up page titles: Put [[Hello World]], not [[Hello_World]].
  • tag long thread mode discussions with "Refactor Me"

Bit longer

About half an hour...

  • find WikiTags and deal with them:
    • Refactor Me tags: clean up bits of discussion ( ThreadMode) and refactor it into  DocumentMode
    • Link Me tags: find the page the writer was thinking of and link it
    • Answer Needed tags: try answer the question the writer couldn't answer himself and integrate it into the page instead of starting to write in  ThreadMode.
  • Create a page that people have made links to, but which doesn't yet exist. Wanted Pages gives a list of these.

Big jobs

Expect to eat dinner late...

  • take part in the Big Cleanup
  • clean up the topic pages
  • clean up tutorials: simplify them by judicious cutting and inserting of basic procedure links
  • clean up images, make a list on Images of files we can delete (or delete them yourself)
    • find unused images
    • find duplicates
    • find dross ([defined])
  • find pages which essentially duplicate each other and merge them

And do a search of Category To Do: Pick a page and make it better!
