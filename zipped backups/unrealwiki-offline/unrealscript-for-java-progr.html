UnrealScript For Java Programmers

Notes for Java developers:

Basics

  • UnrealScript is not case sensitive
  • Structs and Subobjects are always passed by value (deep cloned), and not by a reference. These should not be confused with inner classes.
  • Only certain types (primitives) can be initialized at declaration.
  • Function parameters are cloned(passed by value) unless they are specified as 'out'. Note that the generally by-value nature of uscript presents significant changes in design.
  • Function parameters can be optional
  • function variables must be declared at the beginning of the function, before a call to super.
  • No maps

Initialization

Unlike most java libraries, there is no true initialization hook outside of the default properties section for Actor classes. DefaultProperties initialization works for primitives and passed-by-value complex objects only. You cannot configure complex class instances there and pass them by reference. If you need to initialize a complex object, you can do so in Pre/Post begin play–but those methods are not called in the editor, so they can't be used to setup editable defaults.
