Triggers (UT2004)

UT2004 :: Actor >> Triggers (Package: Engine)

This is the base class of a number of actors designed to do unique things when they are touched and/or triggered. Some subclasses are used to handle the passage of events, while others are used to perform specific tasks that are commonly needed. The base Triggers class has no functionality of its own.

For a summary of what the various classes are used for (though the page is mainly geared toward UT), see types of trigger. For more information and tutorials see the dynamics topic page.

As UT2004 added some new gametypes, there's bound to be new Trigger subclasses. Add them as you find them.
