Map Check Errors

Incomplete list of errors and warnings produced by UnrealEd's Map Check window:

Brushes have NULL material references
Brushes with Null material refs need textures added to them.
Player start not usable
Occurs if the player start is hanging in mid-air so the spawning player will fall to their death (funny but annoying).
Navigation point embedded in level geometry
This usually means a player start is inside solid space and so is not usable. Often accompanied by 'player start not usable'.
Ladder volume is not a ladder volume
A Ladder actor is not contained in a LadderVolume.
