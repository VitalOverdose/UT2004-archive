Blender

Blender is an open source program that can be used to model, UV map (texture baking, LSCM unwrap), animate, render, create games with an internal game engine, and also export meshes for the Unreal engine.

It is developed by the people who use it. The current version at the time of writing is 2.36. Release logs for blender are at: http://www.blender3d.org/cms/Releaselogs.34.0.html

It can be used to create static meshes for the unreal engine via a plugin, exporting UVs, smooth groups and vertex painting.

Export

A plugin for exporting from Blender to .ASE (for UnrealEd) can be downloaded here:

  • http://www.project-blender.onlinehome.de/ – DEAD LINK
   - Direct Link: http://www.project-blender.onlinehome.de/USM%20Demo-File.zip
   - now at http://www.neewo.de/OldSite/index.html
  • http://www.quake3bits.com/htm/tutorials/doom3_models.htm – A fresh site, it is for doom 3, but it still applies to unreal due to the fact that it is a tutorial using the above script ( local copy of it is provided )
   - now at http://www.quake3bits.com/htm/tutorials/doom_3_prepping_models.htm
  • http://www.elysiun.com/forum/viewtopic.php?t=46351&highlight=ase – New ASE exporter (And much better IMO) -zugy

The above was specifically written for use with the Unreal engine.

A tutorial for using the script can be found here:

  • German: http://www.blendpolis.org/f/article_view.php?fldAuto=13&faq=6
  - now at: http://blendpolis.serverpool.org/f/article_view.php?faq=6&fldAuto=13
  • Google English translation: http://translate.google.com/translate?u=http%3A%2F%2Fwww.blendpolis.org%2Ff%2Farticle_view.php%3FfldAuto%3D13%26faq%3D6&langpair=de%7Cen&hl=en&ie=UTF-8&ie=UTF-8&oe=UTF-8&prev=%2Flanguage_tools
  • Direct link to the script on the above mentioned site: http://blendpolis.serverpool.org/t/10unrealed/USM_Export_1.1.py ( this exports ase files )

NB, when using the export script, it will throw an error if it does not find the default .00x after the datablock name of the texture.

Another *.ase export script can be found here, if the above does not work: http://users.durge.org/~andyc/3d/ase-export-filter.html note: this link is outdated.

Import

Depends on your plug-ins, and some file formats that are supported by script include .obj, .3ds (with uv data needing to be redone), .lwo, and .m.

note: .3ds WITH UV can be found at http://home.netspeed.com.au/mcginnes/blender/import-3ds.py

And loads more, just download Blender and look under the import/export menus.
