GameObject

UT2003 :: Actor >> Decoration >> GameObject (Package: UnrealGame)

GameObject is an abstract, notplaceable parentclass for all gameplay-related objects players can pick up. Most (if not all) of these objects need to be brought to a GameObjective actor in order to score.
